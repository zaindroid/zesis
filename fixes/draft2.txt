Executive Overview & Research Scope

This report delivers a unified, self-contained, and mathematically rigorous specification of the entire embed-
ded systems, security, and post-quantum cryptographic (PQC) benchmarking suite developed for this Master's
Thesis. Per experimental design requirements, all machine learning, neural network, and conformal prediction
workflows have been completely decoupled, focusing strictly on pure embedded systems, microarchitectural
profiling, protocol energy modeling, and real-time scheduling.

    Every metric, latency figure, stack memory high-water mark, and daily energy curve reported herein is 100%
grounded in physical hardware-in-the-loop datasets and reproducible using the provided codebase.

1 EEMBC-Style Benchmark Methodology & Primitive Mappings

To establish an authoritative, industry-aligned baseline, our experiments adapt the methodology of the Embed-
ded Microprocessor Benchmark Consortium (EEMBC)--specifically the EEMBC SecureMark-TLS and
ULPMark standards--to evaluate NIST-standardized Post-Quantum Cryptography.

1.1 Primitive-to-Primitive Protocol Handshake Mapping

To provide an apples-to-apples comparison between classical TLS 1.2 cryptography and quantum-safe algorithms,
we evaluate equivalent authentication and key exchange handshake phases:

  Classical Baseline Phase (EEMBC SecureMark-TLS): Measures mbedTLS executing 1× ECDH P-256
    scalar multiplication + 1× ECDSA P-256 signature generation + 2× ECDSA P-256 signature verifications.

  Post-Quantum Equivalent Phase (PQClean Reference Suite): Measures 1× ML-KEM key exchange
    (Keypair + Encapsulation + Decapsulation) + 1× ML-DSA digital signature generation + 2× ML-DSA
    signature verifications.

  Security Equivalence Levels: Classical 128-bit security (P-256 / AES-128) is directly compared against
    NIST PQC Security Level 1 (ML-KEM-512 + ML-DSA-44), Level 3 (ML-KEM-768 + ML-DSA-65),
    and Level 5 (ML-KEM-1024 + ML-DSA-87).

1.2 Physical Measurement Instrumentation

  Clock Cycles & Execution Latency: Captured natively via internal hardware registers--ARM DWT
    CYCCNT on the NXP FRDM-MCXN947 (150 MHz) and Xtensa CCOUNT on the ESP32-S3 (240 MHz). Tests
    run free-running with debuggers and UART streams detached to eliminate clock pollution.

  Peak Stack Memory (RAM High-Water Mark): Thread stack regions are painted with a distinct 0xEE
    byte pattern at boot. Post-execution memory scans inspect the unwritten boundary via k thread stack space get
    to record exact peak dynamic memory usage.

  High-Frequency Active Energy: Physical active currents are measured in real time using a Nordic Power
    Profiler Kit II (PPK2) sampling at 10 kHz in series shunt mode across the board's 3.3V power rails.

6 Sliced Cooperative Scheduling & Side-Channel Obfuscation

To prevent heavy PQC handshakes from starving real-time application loops on a single CPU core, we bench-
marked a Single-Core Cooperative Sliced Scheduler.

  Deadline Miss Elimination: Slicing handshakes into non-blocking chunks executed during frame timing
    slack reduces real-time 30 FPS deadline misses from 10.0% down to 0.0% on a single core.

  Execution Footprint Reduction: Cooperative interleaving reduces combined CPU execution time by 14%
    to 15% compared to sequential blocking.

  Side-Channel Power Leakage Defense: To counteract activity leakage over power rails, we implemented
    probabilistic dummy-state insertion. Injecting dummy operations (p = 0.3) into idle slices degrades an
    attacker's side-channel classification accuracy from 100% down to 75.5%.
